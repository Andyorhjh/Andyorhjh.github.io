## 展示项目：秋招岗位智能监测系统

面向秋招季的一站式岗位情报工具，覆盖「多源采集 → 数据清洗 → 智能匹配 → 综合排序 → 可视化看板」完整链路：

- **多源采集**：异步爬虫框架适配 10+ 类数据源（高校就业网、国家大学生就业服务平台、企业校招官网等），内容哈希去重
- **智能匹配**：jieba 分词 + bge 语义向量模型，简历与岗位 JD 语义级相似度计算，三层门控降低误判，匹配依据可解释
- **综合排序**：「新鲜度 × 匹配度 × 未读状态 × 多样性」四因子加权模型，半衰期指数衰减，已读沉底、同公司降权
- **可视化看板**：FastAPI + SQLite + 原生 JS，赛道筛选、匹配依据悬浮解释、移动端响应式

**项目源码**：https://github.com/Andyorhjh/job-aggregator

## 技术栈

Python · FastAPI · SQLAlchemy · SQLite · jieba · sentence-transformers (bge) · Docker
